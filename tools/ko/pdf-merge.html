PDF를 올리지 않고 합치기

파일을 추가하고 순서를 정한 뒤 하나의 PDF로 저장하세요. 페이지를 이미지로 바꾸지 않고 그대로 복사하기 때문에 글자는 선택되고 이미지는 원래 해상도를 유지합니다.

🔒 파일은 기기 안에서 열리고 합쳐집니다. 전송되지 않습니다.

    PDF 합치는 순서

    1. 파일 추가PDF를 상자에 끌어다 놓거나 상자를 눌러 고릅니다. 파일을 읽으면 페이지 수가 바로 표시됩니다.
    2. 순서 정하기↑↓ 버튼으로 문서를 위아래로 옮깁니다. 합친 결과는 이 목록의 위에서 아래 순서를 따릅니다.
    3. 합치고 저장‘PDF 합치기’를 누르고 잠시 기다린 뒤 저장하세요. 파일은 메모리에서 만들어지고 탭을 닫으면 사라집니다.

    서버 없이 합치기

    온라인 PDF 서비스는 보통 문서를 업로드하고 그쪽 서버에서 합쳐 돌려줍니다. 계약서, 급여명세서, 진료 기록, 신분증 사본이라면 피할 수 있는 위험입니다. 이 페이지는 오픈소스 pdf-lib를 한 번 불러와 브라우저에서 합치기 때문에 파일이 기기 밖으로 나가지 않습니다.

    화질·책갈피·서명은 어떻게 되나

    페이지를 이미지로 바꾸지 않고 페이지 단위로 복사하기 때문에 글자가 선택되고, 페이지 안의 링크도 동작하며, 이미지는 원래 해상도를 유지합니다. 다만 문서 전체 책갈피, 양식 필드, 전자서명은 넘어가지 않습니다. 서명된 PDF는 합친 뒤 서명이 없는 것으로 표시되는데, 파일 내용이 바뀌었기 때문에 당연한 결과입니다.

    자주 묻는 질문

    PDF가 업로드되나요?

    아니요. 합치기는 브라우저 안에서 실행되고 결과는 메모리에서 만들어집니다. 네트워크로 전송되는 것은 없습니다.

    파일 사이에서 페이지 순서를 바꿀 수 있나요?

    화살표 버튼으로 파일 단위 순서를 바꿀 수 있습니다. 파일 안의 페이지 순서는 그대로입니다. 낱장으로 바꾸려면 먼저 PDF를 나눠 주세요.

    합치면 화질이 떨어지나요?

    아니요. 페이지를 이미지로 변환하지 않고 복사하기 때문에 글자가 선명하게 남고 선택도 됩니다.

    암호가 걸린 PDF도 합칠 수 있나요?

    잠겨 있는 동안은 안 됩니다. PDF 뷰어에서 암호를 풀고 보호 없는 사본으로 저장한 뒤 추가하세요.

    몇 개까지 합칠 수 있나요?

    정해진 수는 없고 기기 메모리에 달렸습니다. 보통 문서 10~20개는 휴대폰에서도 되고, 스캔한 수백 페이지는 컴퓨터가 편합니다.

    전자서명은 어떻게 되나요?

    합친 문서는 새 파일이므로 서명은 무효가 됩니다. 법적으로 필요하다면 서명된 원본을 따로 보관하세요.

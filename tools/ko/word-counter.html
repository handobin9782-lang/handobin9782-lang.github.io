단어는 어떻게 세나

영어·스페인어처럼 띄어쓰기로 단어를 구분하는 언어에서는 글자·숫자·아포스트로피가 이어진 덩어리를 한 단어로 셉니다. 워드프로세서와 같은 기준이라 따옴표나 숫자가 두 번 세어지지 않습니다. 한국어와 일본어는 띄어쓰기만으로 단어를 나누기 어려워 브라우저의 기본 단어 분절 기능(Intl.Segmenter)을 씁니다. 사전 분석처럼 정확하지는 않고 실용적인 근사치입니다.

바이트가 왜 중요한가

많은 시스템이 글자수가 아니라 바이트로 한도를 정합니다. SMS 한 통은 160바이트, 데이터베이스 열이나 API 필드가 2,000바이트로 제한되기도 합니다. UTF-8에서 영문자는 1바이트, 한글·일본어·중국어 글자와 이모지는 3~4바이트입니다. 한글 500자는 대략 1,500바이트가 되니, 바이트로 검사하는 입력란에 붙이기 전에 확인해 두면 좋습니다.

읽기 시간과 말하기 시간

읽기 시간은 띄어쓰기 언어 기준 분당 200단어, 한국어·일본어는 분당 500자로 계산합니다. 보통 글을 조용히 읽는 속도 범위입니다. 말하기 시간은 분당 130단어로, 발표할 때 편한 속도입니다. 둘 다 추정치이고, 어려운 전문 글은 더 느리고 쉬운 대화체는 더 빠릅니다.

자주 묻는 질문

입력한 글이 저장되거나 전송되나요?

아니요. 세는 작업은 페이지 안의 자바스크립트로 합니다. 전송도 저장도 기록도 없고, 오프라인에서도 동작합니다.

한글·일본어 단어수는 정확한가요?

글자수는 정확합니다. 단어수는 브라우저의 분절 기능을 쓴 근사치입니다. 번역 견적에는 글자수나 바이트가 더 확실합니다.

글자수와 바이트가 왜 다른가요?

글자는 문자 하나의 수, 바이트는 UTF-8에서 차지하는 저장 공간입니다. 영문자는 1바이트, 한글·일본어·중국어는 3바이트, 이모지는 4바이트입니다.

SEO 메타 설명에도 쓸 수 있나요?

네. 위 표에 흔한 한도를 정리했습니다. 구글은 메타 설명을 보통 155~160자에서 잘라 보여 줍니다.

공백과 줄바꿈도 세나요?

‘공백 포함 글자수’에는 들어가고, ‘공백 제외’와 단어수에서는 빠집니다. 줄바꿈은 두 수치 모두에서 한 글자로 셉니다.
